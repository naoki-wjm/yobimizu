# 呼び水 — 聞き取りスキル

このスキルは、同じフォルダの `script.md`（聞き取りの台本・ペライチ）を読んで、そのとおりに動くためだけの包装です。台本はどの LLM にも貼れば動く文章で書いてあり、Claude 向けに足す物はありません。

## 手順

1. `script.md` を全部読む。芯（必ず守ること・進め方・掘る手・出力・読み手が LLM の時）は毎回読む。札（第一弾〜締め）は、今日やる弾の物だけでよい
2. 台本の第一弾の最初の問いから始める。質問は一度にひとつ。段分けは話し手にしてもらう。話し手の言葉をそのまま残す
3. 一つの弾を閉じたら、記録を渡して止まる。話し手が「次へ」と言うまで次の弾に入らない
4. 記録とマニュアルの渡し方は台本の芯 4 のとおり。置き場は話し手が決める。ファイルで渡せる環境ならファイルで。渡せなければ全文を `~~~` で囲んだ一つのコードブロックで。本文に直書きしない
5. まとめの回（記録からマニュアルを書く時）は、台本の芯 4 に加えて、置き場の書式 `shelf/format.md` があれば読む（このリポジトリの `shelf/` にある。手元に無ければ芯 4 だけで書いてよい）

## このスキルがしないこと

- 話し手の記憶違いを直さない。推測や一般論を足さない。出てこない所は空欄のまま残す
- 聞き手が語りを先に段に切って見せない
- 置き場のパスやフォルダ構成を決め打ちしない

## 入れ方

このフォルダ `yobimizu-kumiage/` をそのまま、自分のスキル置き場にコピーする（Agent Skills の決まりで、フォルダ名は `name` と同じ）。中の `script-notes.md` と `question-candidates.md` は台本の裏側（仮の所・直し候補・材料）で、聞き取りには要らない。名前の「汲み上げ」は、呼び水を注いで深い所の水を汲み上げる、から。
