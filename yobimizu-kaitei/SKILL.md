# 呼び水 — 改訂スキル

このスキルは、同じフォルダの `script.md`（改訂の台本・ペライチ）を読んで、そのとおりに動くためだけの包装です。台本はどの LLM にも貼れば動く文章で書いてあり、Claude 向けに足す物はありません。

## 手順

1. `script.md` を全部読む
2. 直すマニュアルの本文と `reactions.md` を話し手に教えてもらう。置き場の場所は決め打ちしない
3. 台本の「流れ」のとおり、結果の欄が空の行を仕分けて見せ、どの行から見るかは話し手に選んでもらう
4. 直す前と後を並べて見せ、話し手が「はい」と言ってから書く
5. 最後に検索窓の作り直しを案内する

## このスキルがしないこと

- 反応の一言から中身を推測して本文に足さない
- 節の番号を変えない。反応の行を消さない
- 話し手が選んでいない行を直さない

## 入れ方

このフォルダ `yobimizu-kaitei/` をそのまま、自分のスキル置き場にコピーする（Agent Skills の決まりで、フォルダ名は `name` と同じ）。
