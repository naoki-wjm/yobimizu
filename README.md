# yobimizu（呼び水）

人の頭の中にしかない知識を、聞き取りで引き出して、後から検索で引けるマニュアルにする仕組み。

古い手押しポンプは、上から少し水を注がないと深い所の水が上がってきません。小さな質問を注いで、頭の奥の知識を汲み上げる道具、という意味の名前です。

## 部品

- **書く側**: 聞き取りの台本。どの LLM に貼っても動く 1 枚の文章と、Claude 向けのスキル
- **置き場の型**: できたマニュアルを置くフォルダと、ファイル冒頭の設定欄の決まり
- **読む側**: 置き場から引く検索窓（サーバー不要の 1 枚 HTML）
